# Speech-to-Text

> **Payment wires:** every paid endpoint accepts **x402** and **MPP** (Machine Payments Protocol) on the same 402 - see [[Paying with x402]] and [[Paying with MPP]]. Agent402 is the applied layer of [[Agentic Finance]]: agents that pay and get paid on their own.

> **Acceptable use.** Hosted-instance traffic is governed by the [Terms of Service](https://agent402.tools/terms) - including a generative-content acceptable-use policy - and by the upstream model providers' usage policies. Wallets used for prohibited content are blocked before settlement. Outputs are generated by third-party models from your inputs; you are responsible for how you use them.


Two tiers of audio transcription, paywalled via x402. Provide a URL to an audio file, get back the transcript with language detection and duration.

## Tiers

| Endpoint | Price | Model | Max duration |
|---|---|---|---|
| `POST /api/transcribe` | $0.03 | `gpt-transcribe` | 4 min |
| `POST /api/transcribe-pro` | $0.10 | `gpt-transcribe` | 10 min |

Both tiers run the same model and differ only in the duration cap.

## Speaker labels and word timestamps

Add `"diarize": true` for speaker labels and word times (model-backed), at the same price and cap. The answer adds `speakers` (how many were heard) and `words`, each with `start`, `end` and a `speaker` number.

Both tiers are **wallet-only**. See [[Security Model]].

## Supported audio formats

mp3, m4a, wav, ogg, flac, webm (max 25 MB). mp4, mpeg and mpga files are accepted too when their duration can be read; one whose duration cannot be read answers `422` and is not charged on x402. WMA (ASF), raw AAC (ADTS), AMR and CAF files are read too: each is measured by decoding and sent upstream as FLAC. A file with more than one audio track (Matroska, WebM, Ogg, MP4) is measured and transcribed on its first audio track.

## Request / Response

```json
// Request
{ "url": "https://agent402.tools/fixtures/sample-audio.wav", "language": "en" }

// Response
{ "model": "gpt-transcribe", "provider": "agent402",
  "text": "Hello, this is a sample transcription.",
  "language": "en", "duration": 3.5 }
```

Only `url` is required. `language` (ISO-639-1 code) is optional but improves accuracy.

The file's length is measured by decoding it before any upstream call. A file whose length cannot be confirmed is transcribed up to the tier's cap, and the answer says so with two more fields: `trimmedToCapSeconds` (the cap it was cut at) and `durationUnconfirmed: true`. Both are absent from every other answer.
