# agent402-google-adk

Renamed to [`agent402-dev-kit-tools`](https://www.npmjs.com/package/agent402-dev-kit-tools). This name gets no further releases.

```bash
npm i agent402-dev-kit-tools
```

Then import from `"agent402-dev-kit-tools"` where you imported from `"agent402-google-adk"`. The API is the same; nothing else changes.

This last release (0.1.15) depends on `agent402-dev-kit-tools`, re-exports it and prints a one-time deprecation notice, so an existing install keeps working until it moves.
