# elizaos-plugin-agent402

Renamed to [`agent402-actions-plugin`](https://www.npmjs.com/package/agent402-actions-plugin). This name gets no further releases.

```bash
npm i agent402-actions-plugin
```

Then import from `"agent402-actions-plugin"` where you imported from `"elizaos-plugin-agent402"`. The API is the same; nothing else changes.

This last release (0.3.3) depends on `agent402-actions-plugin`, re-exports it and prints a one-time deprecation notice, so an existing install keeps working until it moves.
