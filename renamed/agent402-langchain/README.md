# agent402-langchain

Renamed to [`agent402-structured-tools`](https://www.npmjs.com/package/agent402-structured-tools). This name gets no further releases.

```bash
npm i agent402-structured-tools
```

Then import from `"agent402-structured-tools"` where you imported from `"agent402-langchain"`. The API is the same; nothing else changes.

This last release (0.2.14) depends on `agent402-structured-tools`, re-exports it and prints a one-time deprecation notice, so an existing install keeps working until it moves.
