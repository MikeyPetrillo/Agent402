# agent402-openclaw

Renamed to [`agent402-model-provider`](https://www.npmjs.com/package/agent402-model-provider). This name gets no further releases.

```bash
npm i agent402-model-provider
```

Then import from `"agent402-model-provider"` where you imported from `"agent402-openclaw"`. The API is the same; nothing else changes.

This last release (0.6.3) depends on `agent402-model-provider`, re-exports it and prints a one-time deprecation notice, so an existing install keeps working until it moves.
