# agent402-agentkit

Renamed to [`agent402-action-provider`](https://www.npmjs.com/package/agent402-action-provider). This name gets no further releases.

```bash
npm i agent402-action-provider
```

Then import from `"agent402-action-provider"` where you imported from `"agent402-agentkit"`. The API is the same; nothing else changes.

This last release (0.2.2) depends on `agent402-action-provider`, re-exports it and prints a one-time deprecation notice, so an existing install keeps working until it moves.
