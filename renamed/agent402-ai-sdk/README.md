# agent402-ai-sdk

Renamed to [`agent402-stream-tools`](https://www.npmjs.com/package/agent402-stream-tools). This name gets no further releases.

```bash
npm i agent402-stream-tools
```

Then import from `"agent402-stream-tools"` where you imported from `"agent402-ai-sdk"`. The API is the same; nothing else changes.

This last release (0.2.15) depends on `agent402-stream-tools`, re-exports it and prints a one-time deprecation notice, so an existing install keeps working until it moves.
