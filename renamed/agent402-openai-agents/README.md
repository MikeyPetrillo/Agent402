# agent402-openai-agents

Renamed to [`agent402-runner-tools`](https://www.npmjs.com/package/agent402-runner-tools). This name gets no further releases.

```bash
npm i agent402-runner-tools
```

Then import from `"agent402-runner-tools"` where you imported from `"agent402-openai-agents"`. The API is the same; nothing else changes.

This last release (0.1.15) depends on `agent402-runner-tools`, re-exports it and prints a one-time deprecation notice, so an existing install keeps working until it moves.
