# agent402-anthropic-tools

Renamed to [`agent402-messages-tools`](https://www.npmjs.com/package/agent402-messages-tools). This name gets no further releases.

```bash
npm i agent402-messages-tools
```

Then import from `"agent402-messages-tools"` where you imported from `"agent402-anthropic-tools"`. The API is the same; nothing else changes.

This last release (0.2.3) depends on `agent402-messages-tools`, re-exports it and prints a one-time deprecation notice, so an existing install keeps working until it moves.
